# 오늘의 기록 · 모바일 블로그

흰 배경, 검정·회색 글자, 초록색 강조, 커버·프로필·카테고리·글 목록을 중심으로 구성한 개인 기록형 블로그입니다. 네이버 모바일의 공개 HTML과 CSS를 참고해 독립 화면을 구현했습니다. 네이버 로고, 계정 로그인, 방문자 수 등은 복제하지 않았습니다.

## 실행

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

- 홈: http://127.0.0.1:8080/
- 글: http://127.0.0.1:8080/post.html?post=first-post
- 게시판: http://127.0.0.1:8080/board.html
- 편집실: http://127.0.0.1:8080/editor.html

서버 종료는 Ctrl+C입니다. 파일을 직접 열어도 볼 수 있지만 편집 미리보기·클립보드는 로컬 서버 사용을 권장합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| index.html, css/home.css, js/home.js | 모바일 블로그 홈 |
| post.html, js/app.js | 글 상세와 하단 메뉴 |
| board.html, js/blog-board.js | 게시판·검색·더보기 |
| editor.html, js/editor.js | 여러 글과 프로필 편집 |
| blog-data.js | 프로필과 모든 글 데이터 |
| content.js | 새 글 기본값 |
| assets/images/ | 사진 파일 |

## 이름·프로필·커버

편집실의 홈 설정을 펼쳐 블로그 이름, 프로필 이름, 소개, 커버 이미지 경로를 입력합니다. 기본 이름은 '오늘의 기록', 작성자는 '기록하는 사람'입니다. 실제 이름과 원고는 직접 넣어 주세요.

## 글 추가·수정

1. 편집실에서 새 글을 누릅니다.
2. 주소 ID를 영문 소문자·숫자·하이픈으로 입력합니다. 글마다 달라야 합니다.
3. 제목·작성자·날짜·설명·카테고리를 입력합니다.
4. 글 한번에 넣기로 원고를 붙이거나 문단·소제목·이미지 블록을 추가합니다.
5. 목록에 표시할 글은 공개 설정을 켭니다. 인기글은 운영자 선정 방식이며 실제 조회수 순위가 아닙니다.
6. blog-data.js 다운로드 후 프로젝트의 같은 파일에 덮어쓰고 업로드·재배포합니다.

초안 저장은 현재 브라우저에만 저장합니다. 서버 관리자나 자동 업로드 기능이 아닙니다. 비공개 글도 정적 파일에는 포함되므로 민감한 정보는 넣지 마세요.

## 이미지

사진을 assets/images/photo-01.jpg처럼 넣고 이미지 블록에 그 경로를 입력합니다. 내 PC 이미지 선택 기능은 영문 파일명 사본을 다운로드하므로 해당 파일을 직접 assets/images 폴더에 옮겨 주세요. 공개 HTTPS 이미지 주소도 가능합니다. 목록 썸네일이 없으면 본문 첫 이미지가 사용됩니다.

## 공감·댓글·공유 표시 수치

편집실에서 글을 선택한 뒤 `표시할 공감 수`, `표시할 댓글 수`, `표시할 공유 수`를 입력합니다. 댓글 옆 NEW 표시도 선택할 수 있습니다. blog-data.js를 다운로드해 덮어쓰고 업로드하면 적용됩니다. 파일에서 직접 수정할 키는 likeCount, commentCount, shareCount, commentsNew입니다.

숫자는 수동 설정값이며 실제 서버 통계가 아닙니다. 공감은 설정한 수치만 표시하며 선택/취소 토글은 없습니다. 댓글은 하단 댓글 영역으로 이동합니다. 공유 버튼은 링크 공유/복사 기능이며 표시된 공유 수를 자동 증가시키지 않습니다. 댓글 수 설정만으로 실제 댓글이나 작성 기능이 생성되지는 않습니다.

## URL과 UTM 설정

홈은 https://도메인/, 글은 https://도메인/post.html?post=글ID 입니다. 도메인은 호스팅 배포 후 연결합니다. URL 입력만으로 사이트가 생성되지는 않습니다.

편집실의 유입 링크 UTM 도구에서 소스·매체·캠페인·콘텐츠 등을 입력해 공유 링크를 만들 수 있습니다. 이미 있는 post 매개변수는 유지됩니다.

```text
https://your-domain.example/post.html?post=first-post&utm_source=instagram&utm_medium=social&utm_campaign=journal&utm_content=story_01
```

UTM은 주소 정보이며 통계 저장 도구가 아닙니다. 선택한 글에 본인 G-... 측정 ID를 입력하면 해당 글에서 GA4를 사용합니다. 홈 통계·외부 서비스 계정은 아직 연결하지 않았습니다.

## 배포

현재 소스만 GitHub에 관리합니다. 정적 호스팅에 폴더를 배포하고 나중에 도메인을 연결할 수 있습니다. Cloudflare Pages를 쓴다면 브랜치 main, 프레임워크 없음, 빌드 명령이 필요하면 exit 0, 출력은 루트(.)입니다. 실제 주소는 배포 결과를 확인하세요.

댓글 메뉴는 글 하단으로 이동합니다. 서버 댓글 작성·회원가입·인증은 아직 연결하지 않았습니다. 이전의 글 주소는 내용 정리 과정에서 first-post로 변경했으므로 기존 공유 링크를 사용한다면 새 주소로 바꿔 주세요.

## 검토용 원고와 예시 댓글

첨부 원문은 health-notes-draft 글에 보존했습니다. 편집실에서 선택해 확인할 수 있습니다. 위염·역류질환의 정의 혼동과 식품의 치료 효과, 처방약 대체 주장, 인용 출처는 검토가 필요하여 공개 목록에 포함하지 않았습니다. reviewRequired=true인 원고는 공개 체크 여부와 관계없이 목록·일반 글 URL에 표시되지 않습니다.

원고에는 독자 질문 16개와 작성자 답글 16개로 총 32개의 예시 댓글을 넣었습니다. 모두 예시 배지가 붙으며 실제 독자 후기나 치료 경험이 아닙니다. 본문의 comments 배열에서 author, text, replies를 수정할 수 있습니다. isAuthor=true는 작성자 배지를 표시하며, 날짜가 있는 실제 자료는 date 필드로 표시할 수 있습니다. 예시에는 실제 방문자 사진·날짜·복용 경험을 꾸며 넣지 않았습니다.

답글 버튼은 이미 입력된 작성자 답글을 펼치거나 접습니다. 서버 글쓰기·신고·실제 반응 집계 기능은 제공하지 않습니다. 댓글 자료가 있으면 댓글 수는 답글을 포함한 실제 자료 수로 표시합니다.

의학 검토 참고: [위염 안내](https://www.niddk.nih.gov/health-information/digestive-diseases/gastritis-gastropathy), [역류질환 치료 안내](https://www.niddk.nih.gov/health-information/digestive-diseases/acid-reflux-ger-gerd-adults/treatment).
